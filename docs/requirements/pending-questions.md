## 五、已裁决（不再待确认，记录备查）

- 交付目标 = MVP + 生产级代码质量；等保三级 = 设计目标 + 预留审计接口。
- 架构 = 模块化单体（ADR-0001）；设备侧 ID = uint32（ADR-0002）；业务事实 = 服务端事件（ADR-0003）。
- 技术选型 = PHP 8.5 / Laravel 13 / Ant Design Pro 6.0 / PostgreSQL / Redis / jwt-auth / Scramble（纯 HTML）/ GitHub Actions。
- 客户端 = App / 微信小程序 / Admin Web（移除 User Web）；微信小程序**后端接口**（微信登录 + 订阅消息推送）纳入 Phase 1，**前端不在本项目范围**。
- 账号关联 = App email/password 账号与微信 openid 关联到同一 app_user（共享设备信息）；unionid 预留（未来微信开放平台：公众号/微信支付）。
- 订阅消息模板 ID = 走配置（env/config）留空。
- 公钥状态 = 启用 / 禁用 / 弃用；后台登录 = 仅账号+密码（无验证码）。
